A plugin for increasing focus by turning off CSS classes that are built to show up by design. This was created for my site specifically. To use focus mode on your site your site specific classes will need to be added to phoenix-focus-mode.php to turn them off. USE AT YOUR OWN RISK. It is however, pretty straight forward if you know CSS and it works great.

On mine it removes CTAs, standard page elements, built-in WordPress elements and pre-defined div gaps I created. I use it on my portfolio pages to direct focus on the projects themselves. Example: https://natebal.com/portfolio/google-hq/
